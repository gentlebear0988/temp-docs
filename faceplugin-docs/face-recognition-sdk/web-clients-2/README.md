# Copy of Open Source Web

These are **browser** face recognition + liveness samples (`npm faceplugin` and wrappers). They run in the user’s tab. They are **not** the commercial on-device Mobile SDK and **not** the Linux/Windows HTTP API.

For production accuracy, use [Mobile SDK](../mobile-sdk.md) or [Server SDK](../server-sdk.md) and [request a license](../../request-a-license-and-support.md).
