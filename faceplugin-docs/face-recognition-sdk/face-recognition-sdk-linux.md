# Face Recognition SDK Linux (Recognition + Liveness)

Fully on-premise **combined Face Recognition + Liveness** for Linux / Docker. One license, one API: detect, quality, match, template similarity, and **passive** face liveness on your server. **No** biometric data is sent to Faceplugin cloud.

This is **not** the published [Face Recognition Linux SDK](face-recognition-linux-sdk.md) (recognition only) and **not** the [Liveness Detection Linux SDK](../liveness-detection-sdk/liveness-detection-linux-sdk.md) (PAD only). Until the combined GitHub is public, use those two Apps (two containers) or [contact us](../contact-us.md).

{% hint style="info" %}
The public GitHub repository for this combined SDK is **not published yet**. [Contact us](../contact-us.md) for the package, Docker image, and a license.
{% endhint %}

### FAQ

**Can I merge `far.fpk` and `fal.fpk` into one `lib/cpu` myself?** Do not merge Drive zips. See [Combining products](../resources/choose-a-product.md#combining-products-ekyc).

**Is this the Face Liveness App?** No. Face Liveness is PAD-only on port **8084**.
