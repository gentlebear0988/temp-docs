# Face Recognition SDK Linux (Recognition + Liveness)

Fully on-premise **combined Face Recognition + Liveness** for Linux / Docker. One license, one API: detect, quality, match, template similarity, and passive face liveness on your server. **No** biometric data is sent to Faceplugin cloud.

This combined SDK is a separate product from the published [Face Recognition Linux SDK](face-recognition-linux-sdk.md) (recognition only) and [Liveness Detection Linux SDK](../liveness-detection-sdk/liveness-detection-linux-sdk.md).

The public GitHub repository for this combined SDK is **not published yet**. [Contact us](../contact-us.md) for the package, Docker image, and a license. Until then, use the recognition-only and liveness-only Linux SDKs above.
