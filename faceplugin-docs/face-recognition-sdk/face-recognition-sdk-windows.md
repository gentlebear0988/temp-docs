# Face Recognition SDK Windows (Recognition + Liveness)

Fully on-premise **combined Face Recognition + Liveness** for Windows. Same idea as the combined Linux product: detect, quality, match, similarity, and passive liveness on your machine. **No Docker** on Windows.

This combined SDK is a separate product from the published [Face Recognition Windows SDK](face-recognition-windows-sdk.md) (recognition only) and [Liveness Detection Windows SDK](../liveness-detection-sdk/liveness-detection-windows-sdk.md).

The public GitHub repository for this combined SDK is **not published yet**. [Contact us](../contact-us.md) for the package and a license. Until then, use the recognition-only and liveness-only Windows SDKs above.
