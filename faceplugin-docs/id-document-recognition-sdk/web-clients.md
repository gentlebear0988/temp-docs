# ID Document Recognition web clients

These repos are **HTTP clients / demos**. They do **not** ship `libDocSDK`. Start [Linux](id-document-recognition-linux-sdk.md), [Windows](id-document-recognition-windows-sdk.md), or [Node](id-document-recognition-node-sdk.md) on port **8082**, then open a web UI.
