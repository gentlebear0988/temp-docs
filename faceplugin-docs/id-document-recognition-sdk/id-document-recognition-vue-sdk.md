# ID Document Recognition Vue SDK

Vue web demo for Faceplugin ID Document Recognition. Same HTTP API as Linux / Docker on port **8082**. This is a web client — it does not load `libDocSDK`.

### Setup <a href="#setup" id="setup"></a>

Start the Document Reader API, then run the Vue demo from the repository README.

Point the demo at `http://127.0.0.1:8082`. Parse results with [Document result JSON](document-result-json.md).
