# ID Document Recognition React SDK

React web demo for Faceplugin ID Document Recognition. It is an HTTP client — it does not load `libDocSDK`. Point it at your on-premise Document Reader API on port **8082**.

{% hint style="info" %}
The public GitHub repository for this demo is **not published yet**. [Contact us](../contact-us.md) for the package. Until then, integrate against [ID Document Recognition Linux SDK](id-document-recognition-linux-sdk.md) or [Windows SDK](id-document-recognition-windows-sdk.md).
